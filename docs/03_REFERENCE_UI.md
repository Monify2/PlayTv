# Reference UI Rules

The supplied reference images define the visual direction rather than requiring pixel-for-pixel copying of copyrighted artwork.

## Preserve
- Black/graphite foundation.
- Electric-green active states.
- Compact cinematic cards.
- Dark navigation bars.
- Rounded controls.
- Poster-first browsing.
- Strong contrast between active green controls and graphite surfaces.
- Simple iconography.

## Do not do
- Do not turn every action into a green button.
- Do not add icons merely to fill empty space.
- Do not replace reference controls with unrelated icon styles.
- Do not make the UI look like a generic light Material app.
- Do not use random gradients as the primary visual identity.

## Missing controls
When a feature needs an action that is not shown in the references, use the same established icon family. For grouped secondary actions, use a standard More/overflow icon rather than inventing a new visual symbol.
