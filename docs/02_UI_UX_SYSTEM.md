# UI/UX System

## Visual language
The reference direction is a cinematic black and graphite interface with electric-green accents. Black is the deepest background; graphite is used for cards, panels, controls, and navigation surfaces. White is reserved for primary text and green is used for selected/primary states rather than flooding the interface.

## Core palette
- Background: near-black
- Surface: dark graphite
- Elevated surface: lighter graphite
- Divider: muted graphite
- Primary: electric green
- Primary pressed/darker: deeper green
- Text: off-white
- Secondary text: muted gray-green
- Error: restrained red

The exact palette should remain centralized in the theme rather than repeated throughout widgets.

## Layout
- Mobile-first.
- Compact top utility/header areas.
- Dense content rows and poster grids.
- Rounded cards and controls.
- Persistent bottom navigation.
- Strong hierarchy through spacing, typography, image scale, and surface contrast.

## Icons
Use the reference icon style consistently: simple Material/Cupertino-style line or filled glyphs with restrained visual weight. Do not invent a different icon family.

Reference controls keep their exact icon positions. A More/overflow icon is allowed only for extra actions that are not represented in the reference UI, such as secondary card/list actions.

## Interaction
Buttons should provide visible pressed/selected states. Avoid excessive animation. Loading should feel intentional and cinematic. Images should use placeholders/fades rather than layout jumps.
