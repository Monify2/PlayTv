# Design Components

Reusable components should include:
- PlayTv brand mark
- top bar
- bottom navigation
- poster/movie card
- horizontal content row
- section title
- hero/featured card
- rating/meta row
- green primary action
- graphite secondary action
- filter chips
- season selector
- episode row
- download row/progress
- empty/error state
- loading skeleton
- overflow action menu

Component APIs should be data-driven and avoid embedding business logic.

The More/overflow icon is specifically for additional actions not represented by the reference controls. It is not a replacement for reference icons.
