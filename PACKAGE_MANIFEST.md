# PlayTv complete source package

This package is the authoritative Flutter client source for the current PlayTv build.

Included:
- Flutter application source
- Bunny playback/download client
- Supabase authentication/API client
- ad/reward download flow
- search
- profile/settings
- dark-green theme
- GitHub Actions release workflow
- project documentation

Intentionally generated by CI:
- `android/` — generated by `flutter create --platforms=android`
- build outputs

Backend note:
- Supabase Edge Functions and database are deployed in the PlayTv Supabase project.
- `TMDB_API_KEY` remains a server-side secret and is only checked by CI; it is not embedded in the APK.
